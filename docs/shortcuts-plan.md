# Tab Switch: Alt+W и Alt+T

Статус: согласован пользователем 2026-10-30. Дополнение: toggle-last назначается Alt+A.

## Исследование

Репозиторий: https://github.com/BogdanFlatANDHome/tabswitch.
Локальная копия: /home/bogdan/linux-base/tabswitch; рабочее дерево чистое.
Версия manifest: 1.4.0, совпадает с GitHub. Локальных AGENTS.md и kanban/ нет.

Команды описаны в manifest.json, обработчики — sw.js, переводы — _locales,
документация — README.md. Сейчас Alt+W назначен toggle-last, Alt+Q открывает
переключатель, Alt+Left/Right выбирают соседние вкладки.

Chrome допускает максимум четыре suggested_key, команд без назначения может
быть больше: https://developer.chrome.com/docs/extensions/reference/api/commands.
Сейчас заняты все четыре. Есть браузерные тесты и рецепты just test/lint/check.
Текущие тесты переключения вызывают функции worker напрямую; для новых сценариев
проверять вход через событие команды Chrome, не внутренние функции.

## Предлагаемые изменения

1. Добавить close-current (Alt+W), new-tab (Alt+T). Старую toggle-last сохранить
   с Alt+A (уточнение пользователя). У обеих команд соседних вкладок убрать suggested_key,
   сохранив сами команды: их можно назначить в chrome://extensions/shortcuts.
   Таким образом по умолчанию будут Alt+Q, Alt+W, Alt+T, Alt+A. Alt+T означает без Shift.
   Обновлённые назначения в существующем профиле проверить отдельно: Chrome может
   хранить прежнее пользовательское назначение Alt+W.
2. Вертикально: тест закрытия → FAIL на старом коде → обработчик → PASS;
   затем такой же цикл для создания. Использовать Chrome tabs API, чтобы закрытие
   последней вкладки, новая вкладка и её положение соответствовали браузеру.
   Новая вкладка создаётся активной в текущем обычном окне, в конце полосы.
3. Обновить ru/en описания, README и версию расширения; собрать архив после проверок.

## Приёмка и швы

Швы: manifest/Chrome Commands API (назначения и вход события), Chrome Tabs API
и настоящий браузер (видимые вкладки и активное окно). Собственные модули не мокать;
автоматическая проверка входа команды может подменять только внешнюю границу Chrome.

- Из трёх вкладок Alt+W закрывает текущую; две остальные остаются.
- При двух окнах закрывается вкладка активного окна, второе окно не затрагивается.
- Alt+T создаёт ровно одну новую активную вкладку в том же окне, в конце полосы.
- Команды работают на обычной странице и на chrome:// странице/новой вкладке.
- Alt+Q и команды соседних/предыдущей вкладок сохраняют своё поведение.
- В manifest не больше четырёх сочетаний по умолчанию; Chrome загружает расширение.

Рецепты: существующие just test, just lint, just check, just pack;
добавить just browser-check для воспроизводимой живой проверки через playwright-cli,
скриншота и консоли. Финальная проверка — отдельный тестовый браузер с расширением,
без закрытия пользовательских вкладок. Для сочетаний Chrome проверить возможность
нативной доставки клавиш; синтетическое нажатие страницы не считать доказательством
срабатывания browser.commands.

Проверяет пользователь: физические Alt+W/Alt+T в его профиле и раскладке, если
playwright-cli не может доставить нативные browser shortcuts; при необходимости
назначения в chrome://extensions/shortcuts после обновления. Эту часть не отмечать
успешной по результатам вызова внутренней функции.

Финал: отчёт FAIL → PASS, результаты just check, архив, diff и инструкция обновления.
Публикация в Chrome Web Store не входит в задачу.
